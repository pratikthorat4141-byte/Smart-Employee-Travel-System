 🚖 Smart Employee Travel System

 An AI-Enabled Smart Employee Travel Management System developed using Flutter, SQLite, Provider, and Google Maps to automate employee transportation management.


 📌 Overview

Smart Employee Travel System is designed to simplify and automate employee transportation. It eliminates manual trip assignment by providing intelligent trip management, driver tracking, payment management, OTP verification, and reporting.
